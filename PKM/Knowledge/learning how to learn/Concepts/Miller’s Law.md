## Miller’s Law — Modern Updates (Notes)
Not 7 ± 2 anymore
Real capacity ≈ 4 chunks (Nelson Cowan)
Chunks ≠ items
Depends on meaning, familiarity, complexity
Chunking is key
Experts store more by compressing info using long-term memory
No fixed limit
Memory is dynamic (changes with attention & task)
New models
Resource-based (precision ↓ as items ↑)
Hierarchical chunks (chunks inside chunks)
Practical takeaway
Design for ~3–5 elements max
Reduce cognitive load, group related info
