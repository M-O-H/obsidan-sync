
## Build strong resume

### Work experience
- freelance or real work 
- contribute to big project on github
- personal projects that has impact 

#### Personal Projects
Build in depth projects that relate to real work enterprise projects, that scalable, efficient and handle users operations.

##### How to build in depth project
Pick a problem you care about, don't build random app. (unless you experiment or learning new technologies.)

Build a project that solve real work problem.

##### Learn Just In-Time
learn while building, for example when crossing to  new concepts or technologies start learn about it. no need to learn it before building unless it's essential like programming language.


##### Real world standard
Plan, build, maintain and analysis to real world project standard, covering all stages.

#### Position Yourself For Success
showcase your build in a way that highlight your domain knowledge and problem solving skills.

##### How?
**Document everything**
- readMe file.
- explain problem you solved
- Technologies you used
- Challenges you overcame
- highlight depth on your list of projects
- share your journey on media
